## A3. Payers and extension
Payer declares amountCovered(const Bill&) and name(), with a virtual noexcept destructor. SelfPay returns zero third-party cover; the patient owes the full total. Insurance computes requested cover as total × (1 − copay). In this documented policy, requested cover above the limit is rejected rather than silently clipped; this is the brief's required claim-above-cover condition. GovernmentScheme maps package codes to fixed allowed rates and covers min(total, package rate), rejecting an unknown package. Patient due is total minus amount covered.

A CorporatePayer that covers 90% is added in B4 without editing Bill, any existing bill class, Payer or an existing payer. The construction/composition root adds it, which is expected: the open/closed principle does not mean no application code ever changes.

Alternative: std::function<double(const Bill&)> stores a lambda capturing limit and copay, demonstrated in A3/policy.cpp. Both calls are O(1) for a fixed calculation. A raw function pointer needs separate context for state; a closure bundles it. std::function uses type erasure and may allocate if the captured object exceeds its implementation's inline buffer. A virtual payer has a vptr plus its state. Neither fixed size nor faster dispatch is guaranteed across compilers. For GovernmentScheme, the chosen std::map lookup is O(log p) for p package codes, not O(1).
