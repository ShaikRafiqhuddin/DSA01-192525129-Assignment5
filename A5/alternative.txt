Algorithm ManualCleanup
INPUT: WorkItem
OUTPUT: Result
BEGIN
    Resource ← ALLOCATE RESOURCE
    TRY
        Result ← CALL Process(WorkItem, Resource)
    CATCH ANY ERROR
        RELEASE Resource
        RETHROW CURRENT EXCEPTION
    END TRY
    RELEASE Resource
    RETURN Result
END
This handles this one exit shape; adding an early RETURN inside TRY needs another release. A unique owner instead releases automatically on all exits.
